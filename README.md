# Customer Support Ticket Management Automation Using n8n

## Project Overview

This is a personal portfolio project demonstrating how workflow automation can simplify customer support operations.

The workflow collects customer support requests through an online form, records ticket information in Google Sheets, and sends email notifications through Gmail.

## Objectives

- Automate customer support request collection.
- Reduce manual ticket recording.
- Maintain an organized support ticket tracker.
- Notify the support team whenever a new ticket is submitted.

## Tools and Technologies

- **n8n:** Workflow automation.
- **n8n Form Trigger:** Customer request collection.
- **Google Sheets:** Support ticket tracking and storage.
- **Gmail:** Automated email notifications.

## Workflow Process

1. A customer submits a support request through the online form.
2. n8n captures the customer's name, email address and message.
3. The Edit Fields node organizes the incoming information.
4. Google Sheets automatically records the support ticket.
5. Gmail sends an email notification containing the ticket details.
